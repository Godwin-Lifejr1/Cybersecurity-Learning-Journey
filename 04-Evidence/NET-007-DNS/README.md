# NET-007 — DNS & Packet Analysis Evidence

This directory contains supporting evidence for the DNS and packet-analysis lab.

## Evidence sequence

1. Routing and default-gateway verification
2. Gateway connectivity test
3. ARP neighbour inspection
4. ARP packet capture with tcpdump
5. DNS packet capture with tcpdump
6. DNS lookup with dig
7. dns-lab.pcap opened in Wireshark
8. DNS query/response packet inspection
9. Wireshark dns display filter
10. DNS packet details

## What the evidence demonstrates

The screenshots document practical work across the network stack: local routing information, gateway reachability, ARP resolution, DNS request/response traffic, command-line packet capture, and packet-level analysis in Wireshark.

The screenshots are supporting evidence. They do not by themselves prove mastery of the underlying concepts.
