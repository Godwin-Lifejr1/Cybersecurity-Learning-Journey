# Career Readiness

This section tracks the transition from learning to employable cybersecurity evidence.

## Target roles

Initial targets:
- SOC Analyst
- Cybersecurity Analyst
- Security Operations Analyst
- Junior Network Security Analyst
- IT Support / Security Operations

Longer-term paths:
- Detection Engineering
- Incident Response
- Penetration Testing
- Cloud Security
- Security Engineering

## Interview evidence

For every major project, prepare to explain:
- Objective
- Architecture
- Tools
- Commands
- Expected result
- Actual result
- Troubleshooting
- Security significance
- Limitations
- Improvements

## Resume rule

Resume claims should come from demonstrated GitHub evidence.

Do not claim a technology merely because it appeared in a lesson.

## Portfolio rule

Quality matters more than commit volume.

A recruiter should see a coherent progression from fundamentals to increasingly realistic security projects.
