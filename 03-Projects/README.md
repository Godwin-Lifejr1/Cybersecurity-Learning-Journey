# Cybersecurity Portfolio Projects

This directory contains projects designed to demonstrate practical cybersecurity ability.

## Quality rule

A project is not complete because commands were executed. It must contain evidence, interpretation, troubleshooting, security implications, and a clear explanation of what was learned.

## Current projects

Demonstrates:

## Planned portfolio projects

Projects will be added only after practical work is actually completed.

### Network Troubleshooting Lab
Diagnose a deliberately broken isolated network and produce a professional troubleshooting report.

### Linux Hardening Project
Harden a Linux VM, verify the changes, and document before/after security posture.

### Python Security Log Analyzer
Build a Python tool that parses logs, identifies suspicious patterns, and produces a structured report.

### Detection Engineering Lab
Generate controlled security events, collect telemetry, write detections, investigate alerts, and document the investigation.

### Incident Response Simulation
Investigate a simulated compromise from initial alert through containment, evidence collection, analysis, and final report.

### Authorised Web Security Assessment
Assess an intentionally vulnerable training application and produce findings with impact, evidence, remediation, and retesting.

### Cloud Security Review
Build a small cloud lab and assess identity, network controls, logging, storage, and least privilege.

## Project lifecycle

Idea -> Scope -> Lab -> Evidence -> Analysis -> Report -> Review -> Publish

Only projects satisfying this lifecycle should be presented as completed portfolio work.
